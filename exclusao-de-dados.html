Exclusão de dados

Para apagar os dados que o Fakenômetro tem sobre você, mande uma mensagem direta com a palavra APAGAR para o perfil com que você falou (@fakenometro ou @fakenometer), ou escreva para contato@fakenometro.com.br informando o seu @ do Instagram.
